Terms of Service

Overview

threads_city is an internal content workflow tool for account authorization, manual content review, and controlled publishing. By integrating threads_city with a publishing platform, you agree to these terms.

Service Description

threads_city routes content from source selection through manual review to platform publishing. Content is never published automatically — every piece must be explicitly approved by the project owner through the internal review workflow.

User Responsibilities

The project owner is responsible for:

  • Reviewing all content before it is published
  • Ensuring published content complies with each platform's policies and guidelines
  • Managing and safeguarding OAuth tokens and access credentials
  • Revoking authorization when it is no longer needed

Platform Compliance

threads_city operates within the constraints of each connected platform's API terms and developer policies. The tool does not circumvent rate limits, content restrictions, or publishing rules set by any integrated platform.

Limitation of Liability

threads_city is provided as an internal workflow tool. The project owner assumes responsibility for all content published through the tool and for compliance with all applicable platform agreements.
